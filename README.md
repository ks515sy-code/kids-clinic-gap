## 계산 방법
1. **전문의 수**: 진료과목정보에서 진료과목코드 `11`(소아청소년과) 행의 '과목별 전문의수'를 기관(암호화요양기호)별로 더했다.
2. 병원정보와 '암호화요양기호'로 연결하고, 주소의 앞 두 단어를 시군구로 삼았다.
   - 세종특별자치시는 하나의 시군구로 본다.
   - '광주광역시'·'전라남도'로 시작하는 주소는 '전남광주통합특별시'로 바꿨다.
3. **어린이 수**: KOSIS '데이터' 시트에서 항목 '총인구수[명]'의 `0 - 4세`, `5 - 9세`, `10 - 14세` 값('2026.09 월')을 더했다.
   - 시도 열이 없으므로 시도 이름 행 아래 행을 그 시도의 시군구로 봤다.
   - 전국·시도 합계 행과 '출장소' 행(경기 북부출장소, 강원 동해출장소)은 뺐다.
   - 세종특별자치시는 파일에 시도 행과 시군구 행으로 두 번 나오므로 한 번만 셌다.
4. **지표** = 전문의 수 ÷ 0~14세 인구 × 10,000
5. **순위**: 반올림하기 전 값으로 높은 순서대로 매겼다. 같은 값은 공동 순위(가장 높은 순위)를 준다.

## 검산
- 시군구 수 230곳, 이름이 맞지 않은 시군구 0곳
- 전문의 합계 5,890명 = 진료과목코드 11 행 전체 합계 (병원정보와 연결되지 않은 기관 0곳)
- 0~14세 합계 5,116,175명 = KOSIS '전국' 행의 0~14세 합계

## 한계
- 전문의는 **의료기관 소재지** 기준이다. 아이들이 사는 곳이나 실제로 진료받는 곳과 다를 수 있다. 큰 병원이 모인 지역은 값이 높게 나온다.
- '과목별 전문의수'는 기관이 신고한 수치다. 근무 형태(상근·비상근), 실제 진료 여부, 한 의사가 여러 기관에 등록됐는지는 확인하지 않았다.
- 다른 진료과(가정의학과 등) 의사가 아이를 진료하는 경우는 세지 않았다.
- 어린이는 0~14세로 한정했다. 소아청소년과 진료 대상(청소년 포함)보다 범위가 좁다.
- 구가 있는 시는 시 전체를 한 곳으로 셌다. 시 안의 구별 차이는 드러나지 않는다.
- 어린이가 적은 군은 전문의 1명 차이로 값이 크게 바뀐다.
- 전문의 0명인 23곳 중 소아청소년과로 등록된 기관이 아예 없는 곳: 경상북도 영양군. 나머지는 소아청소년과로 등록된 기관은 있지만 전문의 수가 0이다.
